## ゲーム概要

『PUMPKIN KNIGHT』は、魔女の力を取り戻すため、カボチャの騎士たちを育成して試練に挑むローグライクゲームです。
マモノたちとのバトルやクラフト、さまざまなイベントを通じて騎士を育成。バトルではタイムラインを操作し、スキルを駆使して戦います。戦闘中に新たなスキルが閃くことも！
